# Badge art prompts

One prompt per badge, ready to paste into any image generator. Save each result
as `public/badges/<id>.png` and it appears in the app automatically — no code
change. See `public/badges/README.md`.

**Suggested settings:** square (1:1), 512×512 or larger, transparent background
if your generator supports it. Bold silhouettes read best — these render around
20px, though they're kept large for future use.

**Append this to any prompt** if you want the set to hang together:

> game achievement badge icon, centered emblem on transparent background, thick clean outline, rich saturated colors, subtle inner glow, no text, no letters, crisp at small sizes

Styles are deliberately varied — mix enamel pin, engraved medal, sticker, and
painted crest looks. Unearned badges are drawn greyscale by the app, so one
artwork per badge is enough.

## Batch tips

* **Generate a region set in one go** — ask for four medals of the same
  landmark in bronze, silver, gold and platinum, then split the grid.
* **Type badges** work well as a "sticker sheet" of several at once; the
  silhouettes stay distinct because each element is different.
* If a badge reads muddy at small size, regenerate asking for "fewer details,
  one strong shape, higher contrast".
